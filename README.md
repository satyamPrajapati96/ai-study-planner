# AI Study Planner

An AI-powered study planning web application designed to help students create personalized study schedules based on their subjects, available study time, exam date, weakest subject, and current learning level.

## Features

- Personalized study plan form
- Subject and exam date input
- Daily study hour selection
- Weak subject prioritization
- Beginner, Intermediate and Advanced levels
- Study Schedule
- Progress tracking
- Responsive dashboard UI
- Gemini API integration for AI-generated study plans

## Tech Stack

- React
- JavaScript
- CSS
- Node.js
- Express.js
- Gemini API
- Vite
